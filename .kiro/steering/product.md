# Product Overview

## 概要

Ashiato は StepByCode 運営向けのイベント進行管理プロダクトです。`定例 → 作成 → 広報` の流れを Web アプリと Discord Bot で扱える状態を目指し、運営メンバーの進行管理、状態共有、通知導線を一元化します。

## Core Capabilities

- 定例から広報までの業務フローを Web UI で追跡する
- API を正としたタスク、承認、状態管理を提供する
- 権限に応じた操作制御を RBAC 中心で実施する
- Discord Bot から通知、確認導線、運用補助を提供する
- 監査ログと構造化ログで運用追跡できる状態を維持する

## Target Use Cases

- 運営メンバーが進行中イベントの状態を確認し、次の作業に進む
- 管理者が権限に応じて設定変更や承認を行う
- Discord 上で締切や承認依頼を通知し、運用漏れを防ぐ
- 実装変更時に設計ドキュメントを同期し、認識差分を抑える

## Value Proposition

- フロントエンド、API、Bot、設計ドキュメントを同じリポジトリで管理できる
- API を中心に権限、データ、監査の責務を固定しやすい
- `cc-sdd` により仕様から設計、タスク、実装までを同じ流れで進められる
