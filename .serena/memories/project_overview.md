Ashiato is an event operations management project for StepByCode. Repository is a monorepo-like layout with `frontend/` for a Next.js/TypeScript web frontend, `api/` for backend API, `bot/` for Discord integration, and `doc/` for specs/architecture docs. Current phase is implementation based on design docs. Frontend stack currently includes Next.js 16, React, TypeScript, Tailwind CSS v4, shadcn/ui tooling, and tw-animate-css.
